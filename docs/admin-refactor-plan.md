# Admin Refactor Plan

这份文档已从“改造计划”转成当前边界说明。

## 现在的事实

- 管理端不再包含本地 billing / redeem / wallet 闭环
- 管理端保留用户、Provider、模型、图片任务、漫画任务、设置和观测
- 模型目录接入 NewAPI，同步只保留目录和执行，不保留本地计费
- 运营统计聚焦任务健康、上游成本和处理状态，不展示本地扣费/毛利

## 已移除的内容

- `/admin/billing`
- `/admin/redeem`
- 钱包调账
- 兑换码批次
- 价格矩阵和默认定价
- 本地计费相关 API / 类型 / 页面

## 后续维护原则

- 不再恢复本地 wallet / redeem / pricing 体系
- 任何计费都应在 NewAPI / 总站层完成
- 本仓库只保留模型同步、任务执行、资产和观测
